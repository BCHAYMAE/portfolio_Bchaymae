# Portfolio Website

A modern, responsive personal portfolio website built with React and Vite. Showcasing projects, skills, background, and contact information in a clean, organized layout.

## 🔗 Live Demo

Check out the deployed portfolio: [https://portfolio-bchaymae-nvw1.vercel.app/](https://portfolio-bchaymae-nvw1.vercel.app/)

## 🌟 Features

- **Hero Section** - Eye-catching introduction with your professional profile
- **Projects Showcase** - Display your best work and accomplishments
- **About Me** - Share your background, skills, and experience
- **Contact Section** - Easy way for visitors to get in touch
- **Responsive Design** - Beautiful on desktop, tablet, and mobile devices
- **Modern Stack** - Built with React 19 and Vite for optimal performance

## 🛠️ Tech Stack

- **React** (v19.2.0) - UI library
- **Vite** (v7.2.4) - Build tool and dev server
- **React Icons** (v5.5.0) - Icon library
- **CSS** - Custom styling

## 📁 Project Structure

```
src/
├── components/

```

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio_Bchaymae
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The site will open at `http://localhost:5173`

## 📝 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint to check code quality

## 🎨 Customization

Each component has its own CSS file for easy styling:

- Edit component JSX files in `src/components/` to modify content
- Update corresponding CSS files to change styling
- Modify `src/global.css` for site-wide styles
- Add images and assets to `src/assets/` folder

## 📦 Build & Deploy

To create a production-ready build:

```bash
npm run build
```

This generates optimized files in the `dist/` folder, ready for deployment to services like:
- Vercel
- Netlify
- GitHub Pages
- Traditional web hosting
